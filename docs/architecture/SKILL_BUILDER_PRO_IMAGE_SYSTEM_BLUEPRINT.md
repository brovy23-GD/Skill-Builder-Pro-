# SKILL BUILDER PRO — IMAGE SYSTEM & RESPONSIVE GRAPHICS BLUEPRINT

## 1. Core Rule

Approved Skill Builder Pro creative is the visual source of truth.

Do not create replacement creative for a page that already has approved artwork simply because a new device size or orientation is required. Responsive work must adapt the same approved environment into an intentional device-specific composition.

Approved artwork may only be materially changed when:
1. there is a concrete design or usability problem, and
2. the user explicitly approves the improvement.

Responsive adaptation is not a redesign.

Never mechanically stretch, squash, or blindly center-crop approved landscape artwork into portrait layouts. Each responsive variant must preserve the same environment, visual identity, materials, lighting, Performance Blue discipline, architectural character, branding, hierarchy, focal elements, and intentional negative space for MAUI / WinForms live UI.

## 4. UI / Art Relationship

The environment is the canvas.

Use localized surfaces only where required:
- compact metric surface
- small action card
- localized athlete information area
- compact smoky backing behind text

Avoid massive translucent dashboards, giant opaque black sections, full-screen dark glass panels, and excessive card stacking.

Text contrast is page-specific:
- white/silver on dark local backing
- dark graphite/deep blue-gray on intentionally bright regions
- restrained Performance Blue labels
- compact smoky local backing over complex art

Especially protect readability over bright sky, reflective flooring, stadium lights, hockey ice, and busy architecture.

## 8A. Micro-Detail Clarity Standard

Skill Builder Pro background environments must hold up under close inspection.

**Every intentional environmental detail should remain visible, crisp, and believable — even at distance.**

If there is:
- a bird in a distant tree
- grass texture at the far end of a field
- stitching on a training bag
- bolts in brushed metal
- texture in concrete
- mesh in a net
- seams in leather
- architectural glass framing
- skyline windows
- signage at the back of a facility
- equipment sitting deep in the scene
- distant stadium seating
- trees, fencing, railings, benches, lights, or structural elements in the background

those details should still read clearly enough to feel intentionally rendered.

This does **not** mean every background object should compete for attention.

It means:
- no mushy distance detail
- no fake blur used to hide weak rendering
- no excessive atmospheric haze
- no crushed background blacks
- no muddy textures
- no low-detail filler
- no shallow depth of field that erases the environment
- no soft-focus shortcuts

The visual hierarchy still controls what the eye notices first, but secondary and tertiary details must remain high quality when viewed.

### Elite Detail Requirement

The image should withstand:
- zoomed inspection
- large desktop display
- tablet display
- high-density phone display
- cropping into responsive variants

A premium SBP visual should reveal **more quality the closer it is examined**, not less.

### Depth Without Detail Loss

Use:
- controlled depth
- realistic perspective
- crisp distant architecture
- clean edge separation
- subtle atmospheric perspective only when physically appropriate
- realistic lighting falloff
- sharp material definition
- high-frequency texture where appropriate

Avoid:
- cinematic blur for its own sake
- exaggerated bokeh
- fake fog
- heavy bloom
- background smearing
- soft artificial textures

### Professional Sports-App Standard

Skill Builder Pro should visually compete with top-tier professional sports, performance, broadcast, and training brands.

The standard is:

**Foreground = elite.  
Midground = elite.  
Background = elite.**

No part of the environment should look like filler.

## 21. Resolver Architecture

Runtime image selection must be centralized.

Resolver dimensions:
- Page
- Sport
- FormFactor
- Orientation

Conceptual contract:

```csharp
string GetBackground(
    VisualPage page,
    Sport? sport,
    DeviceFormFactor formFactor,
    DisplayOrientation orientation);
```

Recommended enums:

```csharp
public enum VisualPage
{
    ChooseRole,
    Login,
    AthleteHome,
    Training,
    TrainingBuilder,
    Goals,
    TrophyRoom,
    LockerRoom,
    Notifications,
    DrillLibrary,
    CoachHome,
    ParentHome,
    AdministratorHome
}

public enum DeviceFormFactor
{
    Phone,
    Tablet,
    Desktop
}

public enum DisplayOrientation
{
    Portrait,
    Landscape
}
```

Examples:

```text
AthleteHome + Phone + Portrait
= Backgrounds/Athlete/Home/phone_portrait.png
```

```text
Training + Basketball + Phone + Portrait
= Backgrounds/Training/Basketball/phone_portrait.png
```

```text
TrainingBuilder + Hockey + Tablet + Landscape
= Backgrounds/Builder/Hockey/tablet_landscape.png
```

## 23. Resolver Fallback Order

Recommended:
1. exact page + sport + form factor + orientation
2. same page/sport + closest approved orientation variant
3. approved canonical master
4. explicit page-level neutral fallback
5. never silently substitute unrelated page artwork

If Notifications portrait is missing, do not silently use Athlete Home portrait.
